주의할 기록 정밀도: 아스타나의 복구 대통령령은 2022-09-17 서명됐으나
법령은 첫 공식 게재일부터 시행한다고 명시하며 공식 기록에는 2022-09-19
게재가 확인된다. 이 검수본은 **2022-09-19**를 날짜별 표시 전환값으로 사용한다.
비슈케크의 1991-02-05 복구는 국회 제374-XII호 결의에 근거하며
일부 시청 일반연혁이 언급하는 4월과 구별한다.
두샨베 1929·1961 개칭은 일자에 관한 1차 근거가 일치하지 않아 **연도 정밀도**로만 저장한다.
아시가바트의 1991-10-27 한국어 표기 전환은 현지어 기반의 **판도편집기 편집 관례**이며
그날 실제로 도시가 공식 개칭되었다는 의미가 아니다.

아스타나(1830), 비슈케크(1868), 아시가바트(1881)는 해당 현대 취락의 성립 이전 시점에
한국어 라벨을 표시하지 않도록 `temporalEligibility` 데이터를 보존했다.
이것은 동명 또는 근처에 있던 이전 요새·정착촌·유적을 삭제한다는 뜻이 아니다.

동기화 정본 웹 커밋(지명 명칭 규칙 개정): `bb37f55130eb896aeb7113f90d4542509dbbb3ff`.
1~15차 도시 기록은 이번 정책 개정에서 수정·재검수하지 않았다.
앱 원본 해시: `reports/places/source-manifest.json`에 Git blob SHA로 보존.
JS `v2-snapshot.test.mjs`는 현대 도시 시작/역사명 전환 및 전체 ID 고유성,
C++ `place_sync_contract_tests.cpp`는 연도·일자별 한국어 표기 선택 함수를 검증한다.

실제 지도용 PLAC v2 manifest는 웹·앱 모두 아직 비어 있으며
`main`에는 이번 자료를 병합하거나 게시하지 않았다.
