동기화 정본 웹 커밋(1차 9개 도시 및 델리 다언어 검수): `d426af898ed8784901b235d52e75cab80892a08a`.
1차 도시 9개 명칭 검토 완료. 델리는 1858-11-01 우르두어 대표명 전환(편집상), 1947-08-15 힌디어·우르두어 병기 시작(편집상), 2004-01-26 펀자브어 제2공용어 추가(델리 공용어법 시행)를 기록했다. 무굴기 페르시아어 명칭의 엄밀한 행정상 공식성은 추가 검증 대상으로 보류한다. 2차의 인천·대구·대전 3개도 추가 검수했다. 나머지 2차 6개 및 3~15차는 아직 새 규칙으로 재검수하지 않았다.
서울의 개칭일을 정밀화했다: 한양→한성 1395-07-01(태조실록 음력 6월 6일 소급 양력), 한성→경성 1910-10-01, 경성→서울 1946-08-10(서울시헌장 제1조).
1946-09-28은 서울특별시 설치 미군정 법령 제106호 시행일로 명칭 변경일과 구별한다.
부산의 영문 Pusan→Fusan(1910-08-29)→Pusan(1945-08-15)→Busan(2000-07-07)은 편집상 경계일과 공식 로마자 표기법 시행일을 구별한다.
오사카의 大坂→大阪(1868-06-21)는 大阪府 설치일에 맞춘 원어 대표 표기 전환이다.
베이징의 北京/北平 전환은 1928-06-28·1937-10-12·1945-08-15·1949-09-27, 영어 Peking→Beijing은 1979-01-01을 적용한다.
2차 한국 3개 도시의 원어·영어 시계열: 1910-08-29 일본어식, 1945-08-15 한국어 복귀, 2000-07-07 개정 로마자 표기법 적용.
인천의 공식 제물포시 개칭은 1945-10-10, 인천부 복귀는 1945-10-28. 해당 기간 영문 Chemulpo는 역사적 통용 외칭의 편집상 선정이며 당시 법정 영어명이라고 단정하지 않는다.
대전 1801년 지명은 농촌 취락으로 기록했으며 그 시기에 근대 도시 지위를 소급하지 않았다. 시대별 도시 등급 분류·표시 변경은 이번에 하지 않았다.
앱 원본 해시: `reports/places/source-manifest.json`에 Git blob SHA로 보존.
JS `v2-snapshot.test.mjs`는 현대 도시 시작/역사명 전환 및 전체 ID 고유성,
C++ `place_sync_contract_tests.cpp`는 연도·일자별 한국어 표기 선택 함수를 검증한다.

델리의 동시 사용 원어 2~3개는 검수용 `defaultNativeNames[]`, `displayTimeline[].nativeNames[]` 목록에만 저장했다. 실제 지도에서는 아직 1개 원어명만 지원하며 배율별 표시 정책은 미정이다.

역사도시 생성·소멸 정책(2026-10-09)은 두 저장소의 `reports/places/historical-display-policy.json`에 동일하게 기록했다.
기존 `cityEstablishedFromYear` 등 형성 시점 필드를 보존하면서 차후 검수용 `activeIntervals[]`(시작·종료·재건 복수 기간), `reviewedCoverage`, `lifecycleReviewStatus`의 의미를 정의한다.
소멸한 도시의 역사 레코드는 삭제하지 않고, 다른 곳으로 실제 이전한 새 도시와는 고유 ID를 분리하며 역사적 관계로 연결한다.
연도 단위만 검증된 경계에 임의의 월일을 부여하지 않고 `unresolved`로 유지한다. 도시 등급·지도 배율·요코하마/대전/업의 실제 시작·종료 날짜는 모두 미확정이다.
이번 변경에서는 15개 배치·87개 도시의 데이터·기존 `temporalEligibility`·배포 지도·렌더러를 변경하지 않았다.
실제 지도용 PLAC v2 manifest는 웹·앱 모두 아직 비어 있으며
`main`에는 이번 자료를 병합하거나 게시하지 않았다.
