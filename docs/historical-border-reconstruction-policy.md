# 역사적 국경·해안선 복원 공통 작업 규칙

> **적용 범위:** 판도편집기의 모든 역사적 국제·국내 경계선, 국가·행정구역 외곽선, 하천 경계, 해안선·간척지·도서 변화 복원. 특정 국가·시대에 한정하지 않는다.
>
> **효력:** 웹 `Pando`와 앱 `PandoEditor`의 GIS 조사·판독·수정·검증에 동일하게 적용한다. 국경의 역사적 귀속과 위상적 정합성은 화면 해상도보다 우선한다.
>
> **기본 원칙:** **역사적으로 옳고, 현재 제품의 최대 표시 배율에서 구분 가능한 만큼만 복원한다.** 사료를 정밀하게 확보하는 것과 그 모든 선형 굴곡을 정밀하게 벡터화하는 것은 서로 다른 작업이다.

## 1. 지도 자료 선정 — 축척보다 연대와 출처 우선

| 목적 | 우선 축척 | 선택 기준 |
|---|---|---|
| 국경 전체의 노선·영토 귀속을 훑어보기 | **1:100,000** 안팎 | 전체 경로, 큰 누락·오배치·도서·월경지 확인 |
| 지형·교구·강·취락을 기준으로 국경선 복원 | **1:25,000** 안팎 | **기본 권장 사료**. 확보 가능한 경우 활용하되 의무적으로 찾지는 않는다 |
| 지도 간 불일치 또는 중요한 수로·해안·귀속 문제 | **1:10,000** 안팎 | 문제가 화면에 보이거나 법적·행정적 의미가 있을 때만 추가 조사 |
| 경계 분쟁, 특수한 소규모 영토·제방·지적 문제 | 1:5,000 이상 상세 | 실질적 역사적·위상적 차이가 있을 때만 예외적으로 사용 |

- 지도 발행연도 **및** 원측량·개정·가필연도를 각각 확인한다. 표지 연도만으로 지도 내용의 기준연도를 확정하지 않는다.
- **대상 기준일에 부합하는 자료를 우선한다.** 기준일 이후 지도는 변화 비교나 소급 검증의 보조자료로 쓸 수 있지만, 변경 사실을 검증하지 않고 그대로 해당 시점의 국경으로 확정하지 않는다.
- 공식 측량도·국경조약·획정의정서·공공 GIS의 출처, 당시 법적 규정과 데이터 이용·배포 조건을 기록한다.
- 1:50,000처럼 다른 축척이라도 **연대·제작 경위·품질이 더 정확하고 화면상 충분**하면 우선할 수 있다. 1:25,000이라는 숫자 자체를 달성하려고 작업을 지연하지 않는다.
- 독립성이 없는 비교(예: 현대 교구선을 기준으로 생성한 후보선을 다시 같은 현대 교구선과 비교)는 **역사적 정확도 검증**으로 보고하지 않는다.
- 역사 지도 지오리퍼런싱의 품질·오차 및 국경 기호의 판독 불확실성은 별도로 표기한다. 오래된 지도가 원래 제공하지 않는 정확도를 억지로 만들어 내지 않는다.

## 2. 기본 표시 정밀도 — 2560 CSS px · 최대 확대 · 0.5 CSS px

웹의 현행 평면 지도(`equirectangular`)에 대해 **비교 기준**을 다음과 같이 고정한다.

| 항목 | 기본값 |
|---|---|
| 비교 지도 | 웹 평면 지도; 앱은 동일한 화면상 가시 수준을 기준으로 비교 |
| 비교 시점 | 사용자가 도달할 수 있는 **최대 확대** |
| 현행 웹 최대 확대값 | `flatZoom = 64` (향후 변경되면 현재 값으로 재산정) |
| 기준 표시 너비 | **2560 CSS px** (브라우저·지도 실제 콘텐츠 너비, 모니터 물리 픽셀 수 아님) |
| 목표 | 독립된 역사 경계 후보와 검증된 기준 형상 사이의 **화면상 최대 이탈 0.5 CSS px 이하** |
| 물리 픽셀·DPR | 픽셀 2배인 기기라고 0.5 CSS px를 0.5 물리 픽셀로 재해석하지 않음 |

현재 웹의 기준 너비에서는 (오차가 작고 평면 지도라는 가정 아래)

```text
flatBaseScale = max(30, mapContentWidth / (2π))
flatScale = flatBaseScale × flatZoom
screenDifferencePx ≈ mapContentWidth × flatZoom / 360
                    × hypot(ΔlongitudeDegrees, ΔlatitudeDegrees)
```

따라서 너비 2560, 확대 64에서 **0.5 CSS px = 각도 약 0.00109863°**에 해당한다. 북위 55.28° 부근에서는 동서 변위 약 **70 m**, 남북 변위 약 **122 m** 정도가 각각 0.5px에 해당한다. 이 값은 **국경의 법적 허용오차도 아니고 모든 방향에서 일률적으로 100m를 허용한다는 뜻도 아니다.** 위도·방향·화면 투영 및 데이터 기준에 따라 달라진다.

**반드시 실제 투영 화면에서 검사한다.** 서로 다른 기하의 동일 구간을 교차 대응시키고, 화면 좌표에서 **양방향 최대 최단거리(투영 후 Hausdorff 거리)** 등을 계산한다. 끝점·경계 전환점·하천 합류·공유 국경선 접합은 별도로 검사한다. 단순히 경위도 소수점 자릿수나 정점 개수를 비교하지 않는다.

비교에 쓸 **독립적인 역사 기준선 자체가 없다면 0.5px '통과'라고 선언하지 않는다.** 육안으로 큰 불일치가 없다는 점만 확인한 경우에는 `육안 확인/정량 미측정`으로 기록한다. 불명확한 부분에 대해 의미 없는 소수 m 추적을 강제하는 것도 금지한다.

## 3. 오차 크기와 무관하게 반드시 고칠 사항

아래 사항은 **0.5px보다 작아도 예외 없이** 조사·수정 대상이다.

1. **국가·지방·행정구역·마을의 귀속**이 달라지거나 월경지·고립 영토·섬이 잘못 포함·누락되는 경우.
2. **기준일 오류:** 조약 효력일, 변경일, 점령·실효지배, 제방·간척 완공 전후 등의 시대착오.
3. 국경이 **강의 어느 쪽/중앙/탈베크**, 특정 배수로·교구 경계·분수계 중 무엇을 따라야 하는지 잘못된 경우.
4. 국경선 **단절·교차·역행·중복**, 슬리버·구멍 등으로 편입 또는 공유 경계 토폴로지가 깨진 경우.
5. 외해·하구·간척·수로 변경에 따라 **국가 영토의 존재 자체 또는 연결 관계**가 달라지는 경우.
6. 기존 자료가 새 증거로 **명백한 역사적 오배치**로 판명된 경우. 작은 픽셀 차이를 핑계로 사실 오류를 방치하지 않는다.

## 4. 조사·검증·반영 순서

1. **개요 조사:** 1:100,000 안팎 또는 확보된 적절한 역사 지도로 경계의 큰 진행 방향, 귀속·월경지·해안 변화 확인.
2. **기본 대조:** 가능하면 1:25,000 역사 도엽을 현행 후보선과 중첩하여 국경 분기점·굵은 굴곡·하천·취락 및 오류 의심 위치 **만** 확인.
3. **차이 분류:** `귀속/토폴로지/연대/큰 시각 차이`이면 정밀 조사, `0.5px 이내의 미세한 굴곡`이면 원칙적으로 더 추적하지 않음. 판단 불가능하면 '미확인'이라고 기록.
4. **선별 정밀 조사:** 1:10,000·지적·국경표석 자료는 **문제가 구체적으로 확인된 부분**만 조회. 표석 1개씩을 무조건 측량하거나 과도한 GCP를 배치하지 않음.
5. **정량 확인:** 실제 역사 기준선과 서로 독립적인 후보 자료가 있을 때만 투영 화면상 최대 이탈을 검사. **0.5px 이하이고 §3 예외가 없으면 정밀화 종료**. 0.5px 초과라면 먼저 귀속·큰 형태·제작연도 문제부터 해결.
6. **최종 반영:** 검증된 구간만 원본 마스터에 반영하고, 미검증 구간은 `working` 또는 `provisional` 상태 유지. 양국 공유 경계·접속점·유효성 검사를 거쳐 웹/앱의 관계 자료와 동기화.
7. **인계 기록:** 완료·보류 구간, 사료 기준연도·출처, 화면상 차이(실측/육안 구분), 예외, 수정 파일, 검사 결과, 다음 작업을 짧게 남김.

**검증 종료의 의미:** '현재 제품에서 더 세밀한 벡터화의 실익이 없다'는 뜻이지, 해당 구간에 근현대 지적 수준의 정확도를 보증하거나 사료 검토를 완료했다는 뜻이 아니다.

## 5. 원본 데이터와 표시용 데이터 분리

- 확보한 출처·원본 지오메트리 및 조사 근거는 **마스터 원본**으로 보존한다. 1,343개 정점을 일괄 삭제하거나 줄일 의무가 없다.
- 웹·앱 표시를 빠르게 하려면 **별도의 렌더링용 LOD/단순화 지오메트리**를 파생시키되, 기본 0.5px 기준에서 형태가 유지되는지 검증한다.
- Douglas–Peucker 등 선 단순화는 최적화의 **후보 도구**이지 역사 좌표 검증 도구가 아니다. 표석 원위치, 국경 전환점, 공유 경계 교차/끝점 등 **의미 있는 위상 고정점**을 보호한다.
- 인접 국가·행정구역이 한 경계선을 각각 따로 단순화해 틈·중첩을 만들지 않도록 **공유 선형을 일관되게 처리**한다.
- 렌더링 캐시/LOD 수준은 제품 개정으로 바뀔 수 있다. 사용자가 실제로 도달 가능한 최대 배율·표시 경로를 기준으로 규칙을 재계산한다.
- 앱의 확대 배율 표기가 웹과 다르면 임의로 동일한 숫자를 적용하지 않는다. **동등한 CSS-화면상 분해능** 또는 앱의 더 엄격한 실제 사용 최대 분해능에 맞추어 비교하고 차이를 기록한다.
- 이 규칙은 **작업 선택·검증 지침**이다. 제품의 줌 제한, 렌더러, 좌표 파일이나 자동 검사 로직을 변경하라는 지시가 아니다.

## 6. 보고 상태 구분 및 최소 기록

| 상태 | 의미 |
|---|---|
| `source-indexed` | 원본 지도·연도·서비스 목록만 파악 |
| `overlay-reviewed` | 원본과 후보선을 중첩·육안 검토; 독립 기준선과의 수치 비교는 미완료 가능 |
| `screen-delta-checked` | 독립적인 기준 경계가 존재하여 화면상 위치 차이를 수치로 검증 |
| `historically-verified` | 연대·귀속·필수 위상 조건과 확인된 차이를 함께 검증 |
| `provisional` | 부족한 증거·미해결 예외가 남아 있어 마스터 최종 승격 불가 |

각 구간 기록에는 **적용 날짜 / 소스(측량·발행·개정 연도) / 경계 참조 근거 / 작업 범위 / 실제 검증 방식 / 비교 확대·콘텐츠 너비 / 픽셀 편차 또는 '미측정' / 귀속·토폴로지 예외 / 반영 여부 / 미해결 항목**을 포함한다. 테스트를 수행하지 않았다면 `미실행`으로 기록하고 통과라고 적지 않는다.

## 7. 1914년 독일제국–덴마크 국경 적용 사례

- 0718 Hvidding 서쪽 절반의 1880년 지도와 기존 교구 기반 후보선은 **육안상 큰 이탈 없이 유사**하다. 현 작업상 지위는 `overlay-reviewed`·`provisional`이다.
- 1880년으로 표기된 영상에 **1887년 개통 국경역**이 보이는 연대 불일치는 별도 검증 대상으로 계속 유지한다.
- 화면상 구분하기 어려운 2~7번 표석의 개별 수 m 좌표 추적을 의무화하지 않고, 국경 전환점·역 부근 국부 굴곡·수로·실제 귀속 오류를 우선 확인한다.
- 나머지 0718·0719·0619·0717 도엽에는 같은 규칙을 적용한다. 더 높은 축척 지도를 추적하는 일은 **확인된 예외가 있을 때만** 재개한다.
