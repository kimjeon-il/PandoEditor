# 웹 → Qt 기능 동등성 계약

2026-09-19 사용자 지시: **웹사이트의 각종 기능을 변형하지 않고 그대로 가져온다.**

## 판정 기준

이식 단위의 기준은 Qt에서 비슷한 결과를 만드는 새 기능이 아니라, 실제 웹 코드와 사용자가 거치는 흐름이다. 내부 언어·스레드·위젯 기술은 바뀔 수 있지만 기능의 의미와 사용 계약은 임의로 바꾸지 않는다. 새 기능이 없거나 안전하게 구현되지 않은 경우 미지원으로 남기고, 대체 동작을 이식 완료로 표시하지 않는다.

| 비교 항목 | 유지할 계약 |
|---|---|
| 진입과 순서 | 메뉴·필드·선택 대상·단계·확정/취소 시점. 모든 기능을 임의의 공통 적용 버튼 뒤로 옮기지 않는다. |
| 대상과 제약 | 객체 종류·단일/다중 선택·잠금·부모/국가/레이어 관계·참조 제한 |
| 인수와 값 | 선택지·기본값·단위·허용 범위·정규화·null/미존재/명시값 구분 |
| 편집 결과 | 동일 입력의 객체 ID·좌표·순서·참조·속성·표시 결과 |
| 확정과 이력 | 웹에서 한 동작으로 확정되는 작업의 경계. 실제 복합 작업은 하나의 ChangeSet, 독립적인 필드 change는 각각 확정 |
| 저장과 재열기 | 웹 형식과 앱 형식을 혼동하지 않고 의미상 동일성 검증. 미지원 값은 보존하고 편집 지원과 구별 |
| 실패와 취소 | 부분 적용·묵시적 데이터 삭제 금지. 입력 유지·이력 보존·오래된 결과 폐기 |
| PC와 모바일 | 플랫폼별 도메인 규칙 복제 금지. 각각 실제 UI 진입을 거쳐 같은 명령 결과 확인 |
| 완료 증거 | 원본 경로·커밋·입력 fixture·기대 결과·테스트/화면 기록·미검증 항목 |

원본 단순화, 대체 데이터, 임의 합계 제약, 지원하지 않는 도형 처리, 기능명만 같은 임시 버튼을 동등성 근거로 삼지 않는다. 원본에 존재하지 않는 기능을 추정하여 추가하지 않는다. 플랫폼 파일 선택창·터치 이벤트·작업 스레드 같은 기술 차이는 구현 기록에 따로 적는다. 플랫폼 차이를 기능 축소나 새로운 필수 단계를 만드는 근거로 쓰지 않는다.

## 아직 동등성 완료가 아닌 것

Qt 프로토타입의 RGB 직접 입력·불투명도·사용자 레이어의 잔여 초안 적용/취소 UI와 즉시 명령 연결은 M1.3 회귀를 유지하기 위한 범위다. 이름·메모 두 필드 외에 웹 UI 전체의 이벤트/이력 경계를 검증한 것이 아니다. 웹 전체 메뉴·객체 조작 흐름은 M3–M6의 실제 원본 대조를 거쳐 교체한다.

기존 `web-feature-audit.md`의 웹 기준 17c3dbe를 이 문서 하나로 모두 최신화한 것으로 보지 않는다. 후속 기능마다 실제 원본을 다시 읽고 기준 SHA와 차이를 기록한다. 이번 M1.4는 웹 저장본 가져오기·합병/분할·국경/해안선 알고리즘·분포·역사/GIS·전체 세계지도를 추가하지 않는다.

Android 실기기 입력·한글 IME·SAF·Back·회전과 Windows 네이티브 실행은 해당 플랫폼에서 실제 검증할 때만 완료로 기록한다. 360px QML 모드 테스트는 모바일 공통 경로의 증거이지 Android 실기기 증거가 아니다.

## M2 추가 대조 (2026-09-19)

같은 웹 SHA의 project-migrations/subunit-migration/country-feature/generic-feature-service/source-provenance/version-contract/project-serializer/project-state와 영토·분포·색상 어댑터를 대조했다. 원본 JS로 생성한 v3/v4/v5/scalars 정답과 C++ 결과를 비교하며, 원본 파일 해시는 `tests/fixtures/web-import/provenance.json`에 고정한다. [M2 구현·검증 기록](qt-web-import-implementation.md)이 범위와 입력 한계를 설명한다.

웹 full의 국가·영토와 관계는 매핑하고, 지명·수계·분포·국기·수도·표시/객체 순서·출처와 알 수 없는 값은 보존한다. 기본값/명시값, flag 미존재/null/embedded, 독립 분포 share를 합치거나 바꾸지 않는다. 알려지지 않은 fragment는 지원으로 승격하지 않고 위험 편집을 차단한다. 일괄 원본 archive가 이후 이름·메모 편집을 덮어쓰지 않는다.

M2 보고서는 이식 중인 데이터의 손실/미지원 상태를 확인하는 전환 경계다. 웹판의 일반 편집을 이 보고서나 공통 적용 버튼으로 대체한 것은 아니다. M1.4의 이름·메모 change 확정은 유지하되, 파일 선택/가져오기 보고 도중의 초안 보호만 예외로 한다. country flags·객체별 표시·혼합과 렌더링까지 같아졌다는 의미가 아니며 M3 이후에 각각 원본을 대조한다.
