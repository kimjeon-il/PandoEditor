For each native launch record UTC start/end, PID, executable/fixture SHA256,
retained native process handle, non-null exit code, timeout, stdout, stderr,
expected/processed/passed/failed/skipped case counts, and any unsupported field.
ExitCode null is an observation failure, never exit 0. An executed reduced or
synthetic diagnostic is recorded as DIAGNOSTIC even when all mechanisms pass.
