## 1. 원본 역사 지도 육안 대조

기존 후보선을 1880년 Hvidding 원본 지도에 중첩하여 전체 이미지 1장·상세 이미지 2장을 작성했다. 0719 Spandet 원본을 같은 지리 범위에서 중첩한 접합부 이미지도 1장 작성했다.

- **서쪽 상세 화면**: 국경 표식 약 **8~10번** 및 **8번 부근의 뚜렷한 북동 방향 꺾임**을 현행 교구 기반 후보선이 대체로 따른다.
- **동쪽 상세 화면**: 국경 표식 **10~12번**, 완만한 동남 방향 진행, 도로 교차부에서 기존 후보선과 뚜렷한 경로 불일치가 보이지 않는다.
- **도엽 경계 부분**: **12~13번** 부근에서 0718 Hvidding과 0719 Spandet 지형도상의 역사 국경 진행 방향이 대체로 자연스럽게 연결되며, 현재 후보선에도 끊김이 없다.
- **육안 판정**: 검토한 해상도에서 **대규모 경계선 경로 오류를 발견하지 못함**. 역사 지도에 명시된 정확한 경계 선형을 독립적으로 벡터화하지 않았으므로, **역사적 최대 편차가 0.5 CSS px 이내라고 판정하지 않음**.

## 3. 검증 예외 및 후속 과제

1. Hvidding 도엽은 **1880년 발행**으로 분류되지만, 1차 작업 때 **1887년 개통 국경역으로 보이는 시설**이 지도에 표시됐다는 문제가 제기됐다. 최종 가필·수정 시점은 여전히 미확인이다. 이번 동쪽 구간의 대규모 경로 판독과 별개로 **시대 오류 위험**을 유지한다.
2. 역사 지도 기호가 해당 구간의 국경·취락·행정 귀속에 관한 새로운 증거를 제공하거나 1880~1914년 수로·제방 변동이 발견되면 해당 부분만 다시 조사한다.
3. **0719 도엽 전체**를 검증한 것은 아니다. 이번에는 0718 접점 이후 0719의 처음 약 900 m를 연결 검토용으로 살폈다.
4. 0.5px 이내의 일반적인 미세 굴곡을 일괄적으로 재측량하거나 모든 표석을 수 m 단위로 좌표화하지 않는다. 그러나 역사적 귀속과 선의 연결·교차 오류는 예외 없이 보정한다.

**최종 조치:** 기존 1~26구간 마스터 후보선 유지. 별도의 조각 GeoJSON과 진단 보고서만 작성, 아직 역사 최종 검증 상태로 올리지 않음.
