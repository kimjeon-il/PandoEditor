# 독일제국–덴마크 1914년 국경: Hårup 곡류·Gels Å/Flads Å 합류점 후속 검증

**판정: 1878년 지도에서 화면상 의미 있는 일부 하천 차이를 확인. 1914년 역사적 국경선 수정은 미승인. 마스터 및 26번 이후 임시 경계선은 보존.**

## 대상과 검증 기준

- 기준일 **1914-07-31**.
- 1878년 프로이센 1:25,000 [Hügum 제21도엽](https://www.deutschefotothek.de/documents/obj/71051510) (SLUB WMS ID **10006020**).
- 대조 대상: 0619 Hügum의 현대 교구·수로 기반 임시 국경선 중 **Hårup 부근 물굽이** 및 **Gels Å·Flads Å 합류점** 두 곳만.
- [GIS 공통 규칙](../../../docs/historical-border-reconstruction-policy.md): 웹 평면지도 최대 확대 **flatZoom64**, 지도 콘텐츠 **2560 CSS px**, 화면 차이 **0.5 CSS px**. 국경 시점·하천 규칙·귀속·연결 오류는 이 기준의 예외.
- **0.5 CSS px에 대응하는 각도 차이 0.0010986328125°**를 화면상 띠로 표시. 이 띠는 **실제 1914년 역사 선형을 따서 측정한 Hausdorff 오차가 아님**.
- [성공한 GitHub Actions 지도 대조](https://github.com/kimjeon-il/Pando/actions/runs/37822505181). 아티팩트: **north-schleswig-hugum-1878-two-hotspots**, 원본·중첩 JPG 두 쌍(7일 후 만료). 저작권 검토 없이 스캔을 Git 저장소에 복제하지 않음.
- 원천·화면 메타데이터: `german-denmark-1914-north-schleswig-001-026.0619-hugum-stage4.hotspots.json`.
- 재현 코드: `tools/review_north_schleswig_1914_hugum_hotspots.py`.

## 1. Hårup 부근 — 선별 검증 유지

화면에 **붉은색 현대 후보선**과 **노란색 ±0.5 CSS px 허용 범위**를 표시해 1878년 지형도의 하천 획과 비교했다.

- 역사 도엽의 강 유로는 현대 후보선과 전반적인 동서 흐름을 공유한다.
- **큰 물굽이 한 곳 이상에서는 1878년 하천의 검정 선형이 허용 띠 바깥으로 보이거나 현대 후보선이 옛 물굽이와 다른 방향으로 진행한다.** 단순한 수 m 미세 굴곡으로 치부할 수 없으므로 잠재적 위치 오류로 유지한다.
- 이는 **'1878년 역사 하도 vs 현재 후보선'의 육안 차이**이며, 1914년 7월의 두 자료 중 어느 것이 실제 국경선인지 보여주는 증거는 아니다.
- 지도 자체의 지오리퍼런싱 품질/GCP 잔차와 표시된 하천 기호 폭이 아직 검증되지 않아 정량적인 거리 오차나 1914년 0.5px 통과/불통과 수치를 작성하지 않는다.
- 바로 1:10,000 전구간 자료를 찾거나 790개 점을 새로 디지타이징하지 않는다. 이 지점의 1900~1914년 자료가 확보될 때 **해당 굴곡만** 재판독한다.

대상 확대창(WGS84): **8.8995~8.9120°E, 55.3076~55.3152°N**.

## 2. Gels Å·Flads Å 합류점 — 국경 끝점 보류

- 1878년 지도에서는 Gels Å와 북측 Flads Å의 합류 부근에 별도의 하천 형상이 나타난다. 현대 후보 종점 **(8.88468381°E, 55.32087242°N)**은 이 합류 지역에 위치한다.
- 역사 지도에서 합류 방향과 대체적인 연결 위치는 볼 수 있으나, **1914년 당시의 정확한 합류 좌표와 우안(오른쪽 강변)으로 이어지는 국경 연결점은 검증되지 않았다**.
- 현대 OSM Gels Å 선 끝점과 임시 국경 종점의 0.031m 일치는 같은 현대 계통의 자료 사이의 일치이므로 독립 역사 검증이 아니다.
- 국경획정위원회 1865년 의정서 **Artikel I §§2–3**에서 명시한 강·강변 기준을 별도로 적용한다. **합류점 이후 Flads Å 국경선은 강의 오른쪽 강변**이므로 중심선을 자동 연장하지 않는다.

대상 확대창(WGS84): **8.8775~8.8995°E, 55.3143~55.3265°N**.

## 3. 새롭게 확인한 도엽 개정 이력

[독일 국가지도측량국 1931년 지도 목록](https://doczz.net/doc/5885424/das-reichsamt-f%C3%BCr-landesaufnahme-und-seine-kartenwerke) **Liste A, Hügum 제21도엽**에는 1880년 원발행으로 기재돼 있고 마지막 **전면 정정(Berichtigung)은 `B 1916`**으로 표시돼 있다. `B`는 `eingehend berichtigt`(상세 정정)의 약호이다.

- **1916년은 1914-07-31 이후**이므로, 수정 도엽이 실물로 확보되더라도 해당 지도를 그대로 1914년 상태로 사용할 수 없다.
- SLUB는 현재 확보한 **Hügum의 발행연도를 1878년**으로 기록하지만, 1931년 국가지도 목록은 **1880년**으로 기록한다. 원측량 연도/초판/증쇄·판본 구분일 수 있으나 현재는 **판본 메타데이터 불일치**로 기록한다.
- 덴마크 [Datafordeler의 프로이센 지형도 1877~1912년 시리즈](https://datafordeler.dk/dataoversigt/historiske-kort-og-data/preussiske-maalebordsblade-wms/)에는 후대 도엽 후보가 있을 수 있으나 **Hügum의 1914년 이전 추가 판본 개별 확보에는 실패**했다. 공식 WMS 접근에는 API 키/OAuth가 필요하다.
- 덴마크 **Lave målebordsblade(1901~1971)**는 독일령이었던 남유틀란트의 첫 제작이 1938년이므로 이 지역의 1914년 현황을 직접 복원하는 자료로 간주하지 않는다. 다만 당시 덴마크 영토였던 **강 북쪽**의 별도 도엽·지적 기록은 후속 보조자료로 검토할 가치가 있다.

## 4. 하류 유로 변경을 해석할 때 주의할 점

덴마크 [자연청의 2010년 Gelsbro 하천 통과개선 계획](https://naturstyrelsen.dk/media/0mtes1p0/skitseprojektgelsbrologo1.pdf)은 하류의 상당 구간이 **인공 직강화가 이뤄지지 않은 자연 곡류 하천**이라고 설명한다(7~8쪽). 하지만 자연 하도라도 1878~1914년 사이 유로가 이동할 수 있다.

- 보고서는 Gelsbro 양어장이 **1940년대에 건설**됐으며, 현대 어도 개선을 위해 약 **390m의 하천 신설**(기존 물굽이 약 300m 재이용)을 계획했다고 기술한다.
- 따라서 **Gelsbro 인근의 현대 시설·물길과 1914년 실제 하도 사이 차이**는 별도로 고려한다.
- 위 현대 계획 문서는 **1914년 하도 좌표의 직접 사료가 아니며**, Hårup 중류의 차이가 해당 공사 때문에 발생했다고 단정할 수도 없다.

## 5. 다음 조치

1. **Hårup 큰 물굽이:** 개별 Hügum 1900~1914년 지도 또는 당시 덴마크 측 경계·수로 기록이 나오면 그 부분만 추가 검증. 필요하면 독립 국경선 벡터를 해당 지점에서만 작성해 화면 오차를 측정한다.
2. **합류점:** 1914년 당시 북측 Flads Å의 오른쪽 강변 규칙까지 같이 확인해야 하므로 단순 현대 하천 종점으로 확정하지 않는다.
3. 현재 증거로는 수정할 수 있는 **확정 좌표가 없으므로 마스터 1,343점·26번 잠정 분리 482+862점·0619 후보 790점을 보존한다**.
4. 다음 독립 작업으로 계획했던 **0717 Hvidding-Ufer 해안·제방(약 0.29km)**을 진행하되, 본 문서의 하천/합류점 보류 항목은 최종 1~26 통합검증 시 다시 확인한다.
