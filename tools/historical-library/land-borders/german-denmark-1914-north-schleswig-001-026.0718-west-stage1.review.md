# 1914년 독일제국–덴마크 국경: 1단계(0718 Hvidding 서쪽 절반)

- **대상 구간:** Hvidding 0718 도엽 서쪽 50%, 약 5.94054km
- **시작:** (8.666666667, 55.276881205), **끝:** (8.750261798, 55.274448612)
- **기준시점:** 1914-07-31
- **편집 대상:** 웹·앱 상설 `work/gis`. `main` 미병합.
- **현재 지위:** 지오리퍼런싱 지도 중첩 및 **정성 판독 완료** / **독립적인 역사 국경선 벡터화·미터 단위 편차 측정 미완료** / 기존 후보선 좌표 수정 없음.

## 1. 1차 사료와 지도

1865년 국경획정위원회 문서 Artikel I §2는 1번 표석에서 22번까지의 경계가 Vester Vedsted·Ribe·Seem 교구의 남쪽 경계와 큰 배수로를 따른다고 명시한다.
- 원문 전사: https://da.wikisource.org/wiki/Freden_i_Wien_(1864)_Gr%C3%A6nsereguleringskommissionen
- SLUB 역사 지도: **Messtischblatt 34 Hvidding**, 목록상 **1878년 측량 / 1880년 발행**, 1:25,000.
- 원본 디지털 객체: https://www.deutschefotothek.de/documents/obj/71051522
- 확인된 원본 WMS 계층: `https://wms.kartenforum.slub-dresden.de/map/10006008`, `df_dk_0010001_0718`.
- WMS를 통해 원본 지도와 현대 교구경계 기반 후보선을 약 5.94km 구간에 걸쳐 중첩함. 전체 범위 1장, 상세 2장, 원본만 표시한 이미지 3장을 **임시 GitHub Actions 아티팩트**로 생성. 지도 원본·이미지는 Git 저장소에 커밋하지 않음.

실행 기록: https://github.com/kimjeon-il/Pando/actions/runs/37791021798

## 2. 도엽 자체에 나타난 경계선: 수작업 시각 판독

- 도엽 북쪽의 지도 표기 경계에 **번호가 붙은 경계표식 2·3·4·5·6·7**이 나타남. 1880년 당시의 표식 번호는 이후 화강암 경계석이 반드시 같은 시점에 존재했다는 의미가 아님.
- 해당 경계는 상단의 밀집된 짧은 경계 표식 및 선으로 표시됨. 현행 교구 경계에 기초한 빨간 후보선은 **첫 상세화면과 두 번째 상세화면에서 그 굴곡을 대체로 따라감**.
- 눈으로 확인되는 큰 방향/분기 오류는 발견하지 못했으나, 판본 연대 및 지도 기하정확도 검증 없이 **수 m·수십 m 정밀도를 보증하지 않음**.
- 역/선로 부근 국경선에는 국부적인 굴곡이 있으므로, **기준점·역시설 경계·경계석 위치를 직접 벡터화**하기 전 해당 굴곡을 확정하지 않음.
- 0718 후보선 서쪽 5.94km의 OSM `Grænsegrøften` 근접검사: **121개 표본점 중 56.2%가 현존 지도 배수로 선에서 10m 이내**. OSM 대상 수로가 일부만 존재하므로 나머지 지점을 일괄 오류로 판정하지 않는다.

## 3. 중요한 자료 연대 불일치 가능성

**지도 목록상 1880년 발행**이라고 되어 있으나 WMS로 내려받은 지도 이미지에는 `Bhf. Hvidding`으로 판독되는 국경역/철도 시설이 표시되어 있음. 관련 국경역과 철도는 **1887년 11월 15일 개통**했다는 별도 사료가 있음.

- 덴마크 문화유산청 역사 설명(1887년): https://slks.dk/omraader/kulturarv/bevaringsvaerdige-bygninger-og-miljoeer/bevaringsvaerdige-bygninger-metode/atlas/vadehavet-kulturarvsatlas/kulturmiljoeer/egebaek-hviding-station
- 그랜세스티 역사자료: https://xn--grnsesti-k0a.dk/foelg-stien/vester-vedsted-til-hoem-21-km/graensestationen-egebaek-hviding
- SLUB 공개 카탈로그: `Hvidding. - Aufn. 1878, hrsg. 1880`.

**판정:** 1880년판에 후대 시설이 가필·개정되었는지, WMS 계층이 후대 내용을 포함하는지, 단순한 지도 표기 해석 오류인지 **아직 구분되지 않음**. 지도 이미지의 시설을 1880년 현황이라고 취급하면 연대착오 위험이 있다. 특히 1887년 국경역/철도의 구간은 1914년 당시 국경의 실제 추적에 활용하기 전에 이력 확인이 필요하다.

## 5. 후속 검증 조건

1. 도엽의 **최종 가필·개정일**(특히 1887년 개통 국경역)을 판별하고 1914년 이전/당시 자료인지 판단.

3. 지오리퍼런싱 잔차(GCP) 및 수로 중심선·교구 경계의 정의를 확인.
