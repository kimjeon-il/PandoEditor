# 독일제국–덴마크 1914년 국경 4차: 0619 Hügum 하천 국경

**판정: 1878년 역사 지형도 직접 중첩·육안 판독 완료(overlay-reviewed). 일부 하천 물굽이에서 현대 후보선과 차이가 확인돼 1914년 최종 확정은 보류(provisional).**

## 조사 범위와 사료

- 기준일: **1914-07-31**.
- 도엽: [Meßtischblatt 21 Hügum](https://www.deutschefotothek.de/documents/obj/71051510), 1878년 측량·발행, **1:25,000**, SLUB WMS ID 10006020, 레이어 df_dk_0010001_0619.
- 법적 근거: [1865년 국경획정위원회 의정서 Article I §§2–3](https://da.wikisource.org/wiki/Freden_i_Wien_(1864)_Gr%C3%A6nsereguleringskommissionen). 26번 Gjelsbro부터 Gels Å를 따라 Flads Å 합류점까지 국경. 합류 이후는 **Flads Å의 오른쪽 강변**을 따라 27번으로 향한다.
- [역사적 국경·해안선 복원 공통 규칙](../../../docs/historical-border-reconstruction-policy.md): 평면 최대 확대 64, 2560 CSS px, 표시 정밀화 종료 기준 0.5 px. 하천 경로·연대·국가 귀속·위상 오류는 별도 필수 검증.
- 웹·앱 work/gis에서 작업, main 미변경.

## 3. 관리 자료와 역사 시점

에스비에르시 [Gels Å 하류 규정](https://www.esbjerg.dk/Files/Filer/Energi%20og%20milj%C3%B8/Vandl%C3%B8b%20og%20s%C3%B8er/vandl%C3%B8bsregulativer/Gels%C3%A5%20nedre%20del%20ved%20%C3%85rup.pdf)은 **현대 Gelsbro의 서쪽 다리 끝부터 Gram Å·Flads Å 합류점까지 6,400m**, 당시 규정상의 자연 상태(naturstand) 하천을 설명한다. 규정은 1923년 이후의 행정 결정과 1956·1957년 양어장 관련 결정을 포함한다. **1914년 법정 하천 길이나 당시 합류 위치의 직접 증거가 아니다.**

[Trap Danmark의 Gels Å 기록](https://trap.lex.dk/Gels_%C3%85)은 큰 직강화·재자연화 사례가 Bevtoft 부근 **상류**에 집중돼 있다고 설명한다. 이를 본 하류 구간에 곧바로 적용하거나 하류의 자연 유로 이동이 없었다고 단정하지 않는다.

## 4. 후속 검증 우선순위

1. **Hårup 부근 0619-middle 패널의 눈에 띄는 물굽이 불일치**를 우선 대상으로 설정. 1900~1914년의 해당 도엽이나 동시대 수로·토지 경계 사료를 찾아 시점을 확인하고, 화면상 의미 있는 부분만 선택적으로 추적한다.
2. **0619-confluence 패널의 정확한 합류 지점**을 1914년 자료로 재확인한다. 합류점 이후 Flads Å 오른쪽 강변은 다음 독립 국경 구간으로 처리한다.
3. 미미한 차이를 해결하려고 전체 물굽이를 일괄 1:10,000 이상 재측량하지 않는다. 역사적 귀속·토폴로지 오류가 확인될 때는 픽셀 크기에 관계없이 수정한다.
4. 입증된 부분만 마스터 좌표로 승격하고, 현재 Gels Å 임시 하천선과 1~26번 구간의 원본은 보존한다.

**결론: 0619 도엽 4차 지도 검사 완료. 역사적 합류점 및 Hårup의 일부 큰 곡류 차이를 남긴 채 임시 후보 상태를 유지.**
